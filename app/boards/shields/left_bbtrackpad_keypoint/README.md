# left_bbtrackpad_keypoint

Standalone KEYPOINT hardware shield. For the explicitly named KEYPOINT_M / Dongle build use left_bbtrackpad_keypoint_dongle, which shares this overlay and drivers. Key count, scan transform, keymap, relay behavior and input processors are selected by the board and its configuration, not by the shield name. Both entries address the same sensor pins; do not select both in one build.
